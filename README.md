# Exercícios de Funções e Lógica de Programação — PROA

Repositório com 10 exercícios práticos desenvolvidos durante o curso **PROA**, com foco em funções e lógica de programação.

## Sobre o projeto

As atividades têm como objetivo praticar conceitos fundamentais de programação, desenvolvendo o raciocínio lógico e a capacidade de resolver problemas por meio de funções.

## Exercícios

O código contém 10 exercícios, cada um com sua respectiva função e uma chamada comentada logo abaixo dela, indicando o número do exercício e a atividade proposta.

## Como executar

Para testar um exercício:

1. Abra o arquivo com os códigos dos exercícios.
2. Localize a função que deseja testar.
3. Leia o comentário que identifica o número e o objetivo do exercício.
4. Descomente a chamada da função logo abaixo dela.
5. Execute o programa para visualizar o resultado.

**Observação:** Para testar outro exercício, basta comentar novamente a chamada anterior e descomentar a desejada.

## Conteúdos praticados

- Funções
- Lógica de programação
- Resolução de problemas
- Organização e reutilização de código
